# Procurement Price Prediction UI

Frontend-интерфейс сервиса для прогнозирования итоговой цены закупки в сфере дорожного строительства.

## О проекте

Сервис использует модели машинного обучения для оценки:

- ожидаемого снижения начальной цены контракта
- прогнозируемой итоговой стоимости закупки
- наличия признаков демпинга

Пользователь вводит параметры закупки через веб-интерфейс, после чего frontend отправляет запрос к backend API с моделью CatBoost и отображает результат прогноза

## Архитектура

Проект разделён на две независимые части:

- **Frontend (GitHub Pages)** — пользовательский интерфейс
- **Backend (FastAPI + CatBoost)** — логика обработки данных и ML-модели

Frontend представляет собой статическую веб-страницу, которая взаимодействует с API через HTTP-запросы.

## Логика работы

1. Пользователь вводит параметры закупки
2. Frontend формирует JSON-запрос
3. Запрос отправляется в backend API
4. Backend рассчитывает дополнительные признаки и выполняет прогноз
5. Результаты отображаются в интерфейсе
